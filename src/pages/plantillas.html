Plantillas

Páginas completas y funcionales para arrancar un proyecto, agrupadas por tipo. Ábrelas para probarlas, o copia el código: las rutas se reescriben solas a tu CDN.

Cómo usar una plantilla

  1. Elige tu CDN en Instalación: el código que copias aquí lo usa.
  2. Pulsa Copiar código en la plantilla que quieras.
  3. Pégalo en un archivo .html y ábrelo desde cualquier servidor.

Cada plantilla es un HTML limpio: su CSS y su JavaScript se cargan desde el CDN con archivos julieta-*.css y julieta-*.js, y sus clases, variables e ids llevan el prefijo julieta- para no chocar con los tuyos. Para personalizar, agrega tu propio CSS y JS después de los nuestros.

Los formularios de las plantillas validan y responden en la página, pero no envían datos a ningún servidor: conéctalos al tuyo.
