Instalación

Julieta UI son archivos estáticos: no hay nada que compilar. Sírvelos desde un CDN, pega dos líneas y listo.

  1. Elige de dónde vienen los archivos

    Todos los fragmentos de esta página usan la URL que elijas aquí. Se queda guardada en tu navegador.

  2. Pega estas dos líneas en el <head>

    La hoja de estilos carga todos los módulos CSS. El script registra <al-icon>, el tema, las pestañas, los modales y el resto.

    <link rel="stylesheet" href="{{CDN}}/src/assets/styles/julieta.css">
<script type="module" src="{{CDN}}/src/assets/scripts/julieta.js"></script>

    Seguro por defecto. Estas dos líneas no cambian nada de tu página. Julieta solo da estilo a los elementos con clases al-* y a lo que contienen: no toca box-sizing, márgenes, titulares, enlaces, botones ni el body, y no se apropia de atajos de teclado. Si además quieres su reseteo, su tipografía y su tema en toda la página, agrega class="julieta" al <html> (o a un contenedor).

  3. Usa las clases

    Los componentes se escriben con clases al-*. Los iconos, con <al-icon name="…">.

Personalizar

Cambia los tokens

Todo el diseño sale de variables CSS con prefijo --al-. Sobrescríbelas en tu propia hoja: como Julieta usa @layer, tus reglas ganan sin !important.

:root {
  --al-jacaranda-600: #0f766e;   /* tu color de marca */
  --al-radius-full: 12px;        /* botones menos redondos */
  --al-font-display: "Fraunces", serif;
}

Tema claro y oscuro

Con class="julieta" en el <html> sigue al sistema por defecto; sin esa clase, los componentes siguen el esquema de color de tu sitio (por ejemplo, color-scheme: dark). Para ofrecer un interruptor, añade un botón con data-al-theme-toggle; la preferencia se guarda sola. Para evitar el parpadeo al cargar, copia este script antes de la hoja de estilos:

<script>
  try { var m = localStorage.getItem("julieta-theme");
    if (m && m !== "system") document.documentElement.setAttribute("data-theme", m);
  } catch (e) {}
</script>

Fuentes

julieta.css pide Bricolage Grotesque, Hanken Grotesk y JetBrains Mono a Google Fonts. Si prefieres alojarlas tú, usa tokens.css y base.css sueltos y declara tus propios @font-face.

Con frameworks

Julieta solo necesita clases y un script de módulo, así que funciona en cualquier stack. Para React, Vue, Svelte o Astro, carga las dos líneas en el HTML base y escribe las clases como siempre.

export function Guardar() {
  return (
    <button className="al-btn al-btn--primary" onClick={() => Julieta.toast.success("Guardado")}>
      Guardar cambios
    </button>
  );
}

API de JavaScript

El objeto window.Julieta existe en cuanto carga julieta.js. También se anuncia con el evento al:ready.

MétodoPara qué sirve
Julieta.toast({ title, text, type, duration, action })Muestra una notificación. Atajos: toast.success, .error, .warning, .info.
Julieta.confirm({ title, text, danger })Diálogo de confirmación; devuelve una promesa true o false.
Julieta.modal.open(sel) / .close(sel)Abre o cierra un <dialog>.
Julieta.theme.set("light" | "dark" | "system")Cambia el tema y lo guarda.
Julieta.command.open(texto)Abre la paleta de comandos.
Julieta.chart(el, config)Dibuja una gráfica en un elemento.

Julieta.copy(texto)Copia al portapapeles; devuelve una promesa.
Julieta.catalog.build()Devuelve el catálogo completo de recursos.

Publicar tu propia copia

Julieta es una carpeta de archivos estáticos, así que cualquier servicio que los sirva con los tipos MIME correctos funciona como CDN. Las dos opciones más rápidas:

GitHub Pages

  1. Sube este proyecto al repositorio julietalibreria.github.io.
  2. Activa GitHub Pages en la rama principal.
  3. Usa https://julietalibreria.github.io como URL base.

jsDelivr con GitHub

https://cdn.jsdelivr.net/gh/julietalibreria/julietalibreria.github.io@1.0.0

Para jsDelivr crea antes la etiqueta de versión v1.0.0. Para probar en local, sirve la carpeta con cualquier servidor estático (por ejemplo npx serve); abrir los archivos con file:// no funciona porque los módulos ES y fetch requieren HTTP.
